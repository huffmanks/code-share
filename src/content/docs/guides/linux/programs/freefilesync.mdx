<Steps>

1.  ## Download

        [Download latest version for Linux x86-64](https://freefilesync.org/download.php).

2.  ## Extract

        ```sh preserveIndent wrap
        tar -xvzf ~/Downloads/FreeFileSync_*_Linux_x86_64.tar.gz -C ~/Downloads/
        ```

3.  ## Make executeable

        ```sh preserveIndent wrap
        chmod +x ~/Downloads/FreeFileSync_*_Install.run
        ```

4.  ## Run

        ```sh preserveIndent wrap
        ~/Downloads/FreeFileSync_*_Install.run
        ```

5.  ## Install

        ### Accept license
        - Press `y` to agree and continue.
        - Press `s` to show details.
        - Press `n` to cancel.

        ### Change install settings (optional)
        - Press `1` to disable for all users.
        - Press `2` to change installation directory.
        - Press `3` to disable desktop shortcuts.
        - Press `Enter` to begin installtion.

6.  ## Synchronization Settings

        ### Comparison
        - **Select a variant:** `File time and size`

        ### Filter
        - **Include:** `*`
        - **Exclude:**
                <Code lang="txt" code={ffsExclude} />

        ### Synchronization
        - **Select a variant:** `Mirror`
        - **Delete and overwrite:** `Recycle bin`

</Steps>
