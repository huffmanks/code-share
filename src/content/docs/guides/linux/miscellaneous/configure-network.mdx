import { netplanConfig, systemdResolvedConfig, wifiPowerSaveOnConf } from "@/lib/mdx-constants";

<Steps>

1.  ## Install network driver (if applicable)

    <Code lang="sh" wrap preserveIndent code={`lspci -nnk | grep -iA 3 net`} />

    If the network controller says **“Broadcom”** and **“BCM43xx”**, install the drivers below; otherwise, skip to step 2.

    <Tabs syncKey="network-driver">

      <TabItem key="modern" label="Modern kernels 6.8+">

            Ensure the `non-free` repository component is enabled for your Debian release. (`deb` and `deb-src`)

            <Code lang="sh" wrap preserveIndent code={`sudo nano /etc/apt/sources.list`} />

            Update package lists.

            <Code lang="sh" wrap preserveIndent code={`sudo apt update`} />

            Check that the Broadcom driver package is available.

            <Code lang="sh" wrap preserveIndent code={`apt-cache policy broadcom-sta-dkms`} />

            Install the kernel headers, DKMS, NetworkManager and the Broadcom driver.

            <Code lang="sh" wrap preserveIndent code={`sudo apt install -y linux-headers-$(uname -r) dkms network-manager && sudo apt install -y broadcom-sta-dkms`} />

            Verification: If the output includes `wl` with a _nonzero size_, the driver module is loaded.

            <Code lang="sh" wrap preserveIndent code={`sudo modprobe -r b44 b43 b43legacy ssb brcmsmac bcma && sudo modprobe wl && lsmod | grep wl`} />

            Remove any wireless interfaces if they exist.

            <Code lang="sh" wrap preserveIndent code={`sudo nano /etc/network/interfaces`} />

            Disable Wi-Fi power saving to help prevent connection drops.

            <Code
                  lang="sh"
                  wrap
                  preserveIndent
                  title="/etc/NetworkManager/conf.d/default-wifi-powersave-on.conf"
                  code={`sudo nano /etc/NetworkManager/conf.d/default-wifi-powersave-on.conf`}
            />

            <Code
                  lang="sh"
                  wrap
                  preserveIndent
                  code={wifiPowerSaveOnConf}
            />

            Restart NetworkManager.

            <Code lang="sh" wrap preserveIndent code={`sudo systemctl restart NetworkManager`} />

            Configure the corporate Wi-Fi connection using WPA-Enterprise credentials.

            <Code lang="sh" wrap preserveIndent code={`sudo nmcli connection add type wifi con-name corporate-wifi ssid "YourSSID" wifi-sec.key-mgmt wpa-eap 802-1x.eap peap 802-1x.identity "your_username" 802-1x.password "your_password" 802-1x.phase2-auth mschapv2`} />

            Connect to the corporate Wi-Fi network.

            <Code lang="sh" wrap preserveIndent code={`sudo nmcli connection up corporate-wifi`} />

      </TabItem>

      <TabItem key="older" label="Older kernels">

            <Code
                  lang="sh"
                  wrap preserveIndent
                  code={`sudo apt update && sudo apt install linux-headers-$(uname -r) -y && sudo apt install bcmwl-kernel-source -y`}
            />

      </TabItem>

    </Tabs>

    For changes to take effect, reboot the system.

    <Code lang="sh" code={`sudo reboot`} />

    Verify the driver is active by running `ip link`. A wireless interface, typically `wlan0`, should now appear in the list.

2.  ## Install and enable wpa_supplicant

    <Code
      lang="sh"
      wrap
      preserveIndent
      code={`sudo apt install wpasupplicant -y && sudo systemctl enable --now wpa_supplicant`}
    />

3.  ## Create symlink to systemd-resolved

    <Code
      lang="sh"
      wrap
      preserveIndent
      code={`sudo ln -sf /run/systemd/resolve/stub-resolv.conf /etc/resolv.conf`}
    />

4.  ## Network configuration

      <Tabs syncKey="network-config">

         <TabItem label="systemd-resolved">

            ### systemd-resolved

               <Steps>

               1. Open netplan config

                     <Code lang="sh" wrap preserveIndent code={`sudo nano /etc/systemd/resolved.conf.d/10-override-dns.conf`} />

               2.  Update config

                     <Code lang="yaml" wrap preserveIndent title="/etc/systemd/resolved.conf.d/10-override-dns.conf" code={systemdResolvedConfig} />

               </Steps>

         </TabItem>

         <TabItem label="netplan">

            ### netplan

               <Steps>

               1. Open netplan config

                     <Code lang="sh" wrap preserveIndent code={`sudo nano /etc/netplan/50-cloud-init.yaml`} />

               2.  Update config

                     - Replace `enp3s0` with your ethernet ID from `ip link`.
                     - Replace `wlan0` with your Wi-Fi ID from `ip link`.
                     - Replace `Your_SSID_Name` and `Your_Password` under access-points.

                     <Code lang="yaml" wrap preserveIndent title="/etc/netplan/50-cloud-init.yaml" code={netplanConfig} />

               3.  Apply the config

                     <Code lang="sh" wrap preserveIndent code={`sudo chown root:root /etc/netplan/50-cloud-init.yaml && sudo chmod 600 /etc/netplan/50-cloud-init.yaml`} />

               4.  Apply the config

                     <Code lang="sh" code={`sudo netplan apply`} />

               </Steps>

         </TabItem>

      </Tabs>

    <br />

5.  ## Restart systemd-resolved

    <Code lang="sh" code={`sudo systemctl restart systemd-resolved`} />

6.  ## Enable systemd-networkd-wait-online

    <Code
      lang="sh"
      wrap
      preserveIndent
      code={`sudo systemctl enable systemd-networkd-wait-online.service`}
    />

7.  ## Reboot the system

    <Code lang="sh" code={`sudo reboot`} />

</Steps>
