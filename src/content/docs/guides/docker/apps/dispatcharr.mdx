## Setup

### M3U account

- **Name:** `Sports M3U IPTV.org`
- **URL:**
  ```txt
  https://iptv-org.github.io/iptv/categories/sports.m3u
  ```
- **Account type:** `Standard`

Another option:

- Generate m3u and epg data: <a href="https://livetvbuilder.replit.app" target="_blank" rel="noopener">https://livetvbuilder.replit.app</a>
- Download and add to `./epg-data` directory.

### EPG

- **Name:** `Sports EPG IPTV.org`
- **URL:**
  ```txt
    http://{{SERVER_IP_VAR}}:3010/guide.xml
  ```
